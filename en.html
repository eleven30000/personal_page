Master's Thesis 2026/07

Distilling Visual Contrastive Decoding into a Single Model for Enhanced Inference and Hallucination Mitigation

Visual Contrastive Decoding Distillation (VCDD) for Efficient and Faithful Multimodal Generation

Knowledge Distillation Hallucination Mitigation LoRA VLM PyTorch
Overview

Large Vision-Language Models (VLMs) frequently suffer from "hallucination"—generating textual descriptions inconsistent with the input visual content. While existing approaches like Visual Contrastive Decoding (VCD) are effective, they necessitate two forward passes during inference, doubling computational overhead and inference latency.

This thesis proposes VCDD (Visual Contrastive Decoding Distillation), which leverages knowledge distillation to compress VCD's contrastive hallucination-mitigation capability into a single compact LoRA adapter. This enables LLaVA-1.5-7B to operate under single-pass inference while simultaneously maintaining high efficiency and factual reliability.

Technical Approach

Methodology Core

  • Smooth-AW KL Distillation: Adaptive Weighting intensifies supervision on difficult, hallucination-prone tokens with probability smoothing to prevent gradient explosion.
  • Anti-Catastrophic Forgetting Regularization: Employs a KL penalty to restrict the student model from diverging from original LLaVA distributions, retaining general conversational competence.
  • Token-Level Signal Transfer: Supervised during training with contrastive distributions from VCD as soft labels, enabling the LoRA module to absorb anti-hallucination behavior.

Video Attention Query Filtering Technology

Video Transformer Query Filtering with Foreground/Background Attention

P52140051TW (Patent Pending) PythonPyTorchVLM
Overview

When processing extended video streams, Video Transformers incur massive computational costs by computing attention over vast numbers of visual tokens, resulting in sluggish inference and posing severe barriers for edge deployment.

This research co-developed a foreground/background query filtering and pooling mechanism that condenses relatively unimportant background information while preserving critical semantic tokens, substantially reducing Transformer computation while maintaining model accuracy. A Taiwan patent application has been officially filed.

Core Mechanisms

  • Foreground Query Filtering: Leverages custom algorithms to extract semantic foreground tokens in videos, retaining essential visual cues.
  • Background Query Pooling: Performs spatial pooling on low-semantic background regions, compressing computation without discarding global context.
  • Challenging Sign Language Validation: In high-information-density sign language videos, leveraged pose/skeleton algorithms to distinguish foreground gestures from background, demonstrating practical feasibility in real-world everyday contexts.

Course Project 2024/09 – 2024/12

Multimodal Campus Security System with VLM & RAG

Multimodal Campus Security System with VLM + RAG

AIoT RAGRaspberry Pi LINE BotVLM
Overview

Constructed a multimodal campus safety pipeline combining VLM camera scene understanding with environmental temperature/humidity telemetry for real-time risk evaluation. Integrated a three-tier architecture:

  • Edge Layer (Raspberry Pi): Ingests camera streams and sensor data, performs lightweight preprocessing, and uploads to processing server.
  • Intelligence Layer (VLM + RAG): Uses VLM to parse scene semantics, with RAG querying campus safety SOP knowledge bases to evaluate threat severity.
  • Notification Layer (LINE Bot): Automatically dispatches real-time alerts and structured incident summaries to administrators based on risk tiers.

Transformer Coil Winding Parameter AI Recommendation System

Transformer Coil Winding Parameter Recommendation System

Full-Stack PythonJavaScriptAPIs
Overview

In collaboration with industry partners, developed a regression-based recommendation system mapping transformer electrical specifications (voltage, current, frequency, core material, etc.) to optimal winding parameters (turns, wire gauge, layers), substantially cutting manual trial-and-error engineering time.

  • Backend: Python API receives specification inputs, invokes regression models to compute recommended parameters, and returns structured outputs.
  • Frontend: JavaScript interactive UI enabling engineers to input specs dynamically, obtain recommendations, and inspect visualized designs instantly.
  • Data-Driven: Trained on historical design cases, supporting multiple core types and complex coil geometries.
