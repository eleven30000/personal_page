碩士論文 2026/07

Distilling Visual Contrastive Decoding into a Single Model
for Enhanced Inference and Hallucination Mitigation

Knowledge Distillation Hallucination Mitigation LoRA VLM PyTorch
Overview

大型視覺語言模型（VLMs）存在「幻覺」問題，常生成與圖像不符的文字。現有解法 Visual Contrastive Decoding（VCD）雖有效，但需同時運行兩路模型，推理成本倍增。

本論文提出 VCDD（Visual Contrastive Decoding Distillation），透過知識蒸餾將 VCD 的防幻覺能力壓縮進單一 LoRA 適配器，使 LLaVA-1.5-7B 在單路推理下同時兼顧效率與可靠性。

Technical Approach

方法核心

  • Smooth-AW KL 蒸餾：以 Adaptive Weighting 加強難樣本學習，並平滑機率分布防止梯度爆炸。
  • 防遺忘正則化：以 KL 散度懲罰學生模型偏離原始 LLaVA 的程度，維持一般性能。
  • Token 級訊號轉移：訓練階段以 VCD 輸出作為 soft label，讓 LoRA 吸收其防幻覺行為。

影片注意力查詢過濾技術

Video Transformer Query Filtering with Foreground/Background Attention

P52140051TW 申請中 PythonPyTorchVLM
Overview

Video Transformer 在處理長影片時，注意力機制會對大量的視覺 Token 進行計算，導致計算量隨影格數二次方成長，效率低落。

本研究共同開發前景 / 背景查詢過濾與池化機制，在保持模型準確度的前提下，大幅削減 Transformer 的計算負擔，並已提交台灣專利申請。

Technical Approach

核心機制

  • 前景查詢過濾：利用注意力分數識別語義相關的前景 Token，保留關鍵視覺訊息。
  • 背景查詢池化：對低語義區域進行空間池化，在不損失全局訊息的前提下壓縮計算量。
  • 消融實驗：以 Python / PyTorch 實現原型，系統評估不同過濾比例下效率與準確度的權衡。

結合 VLM 與 RAG 之智慧安防系統

Multimodal Campus Security System with VLM + RAG

AIoT RAGRaspberry Pi LINE BotVLM
Overview

建構多模態校園安全管線，結合 VLM 攝影機影像場景理解與溫濕度感測器數據進行即時風險評估。 整合三層架構：

  • 邊緣層（Raspberry Pi）：收集攝影機影像與環境感測數據，輕量化前處理後上傳。
  • 智能層（VLM + RAG）：以 VLM 解析場景語義，RAG 查詢校園安全 SOP 知識庫評估威脅等級。
  • 通報層（LINE Bot）：依風險等級自動發送即時警報與場景摘要給管理員。

變壓器線圈繞線 AI 推薦系統

Transformer Coil Winding Parameter Recommendation System

Full-Stack PythonJavaScriptAPIs
Overview

與業界合作，開發將變壓器電氣規格（電壓、電流、頻率、鐵芯材質等）自動映射至最佳繞線參數（匝數、線徑、層數等）的迴歸推薦系統，大幅減少工程師設計流程中的人工試錯時間。

  • 後端：Python API 接收規格輸入，呼叫迴歸模型計算推薦參數，回傳結構化結果。
  • 前端：JavaScript 互動介面，工程師可即時填入規格、取得繞線建議與可視化結果。
  • 資料驅動：以歷史設計案例訓練迴歸模型，支援多類型鐵芯與多種線圈結構。
